In this IoT Lab, we will mainly use the **ESP32** for practical IoT projects.

Before starting the projects, make sure your ESP32 is correctly configured in Arduino IDE.

## Start Here

Continue to [**ESP32 with Arduino IDE**](http://localhost:4321/microcontrollers/esp32-arduino-ide/)

You will learn how to:

- Install ESP32 support in Arduino IDE
- Select the correct ESP32 board
- Select the correct port
- Upload a test program
- Check the output using Serial Monitor

After completing the setup, you are ready to start the practical IoT projects.
