# Welcome to IoT Lab

Welcome to **Internet of Things Lab**, a beginner-friendly guide for learning the Internet of Things (IoT).

This documentation is designed to help students understand IoT step by step, from basic concepts to building simple projects using microcontrollers, sensors, displays, and internet connectivity.

## What You Will Learn

In this IoT Lab, you will learn:

* What IoT is and how it works
* How to use microcontrollers such as ESP32 and NodeMCU
* How to connect sensors and output devices
* How to send data through Wi-Fi
* How to create simple IoT monitoring and control systems
* How to build practical IoT projects

## Start Here

If you are new to IoT, follow these sections first:

1. **What is IoT?**
   Learn the basic concept of the Internet of Things.

2. **What You Need**
   Learn about the hardware and software needed to start building IoT projects.

3. **How to Use This Lab**
   Learn how to follow the tutorials and project guides.

## What We Will Use

Most projects in this documentation will use beginner-friendly hardware such as:

* ESP32
* NodeMCU ESP8266
* Sensors
* OLED displays
* LEDs and buzzers
* Small DC motors and pumps
* Wi-Fi
* Arduino IDE
* IoT platforms

You do not need advanced programming knowledge to begin. Each tutorial will explain the connection, code, and working principle step by step.

## Ready to Start?

Continue with **What is IoT?** to understand how IoT devices collect data, communicate, and perform useful tasks.
