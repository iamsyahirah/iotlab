Before you start building IoT projects, you need some basic hardware and software.

You do not need to buy many components at the beginning. Start with a microcontroller, a few sensors, and simple electronic components.

## 1. Microcontroller

The microcontroller is the main controller of the IoT system.

In this IoT Lab, we will mainly use:

- **ESP32**
- **NodeMCU ESP8266**

These boards are suitable for IoT projects because they have built-in Wi-Fi.

## 2. Sensors

Sensors are used to collect information from the environment.

Some common sensors are:

- DHT11 temperature and humidity sensor
- Soil moisture sensor
- LDR light sensor
- Ultrasonic sensor
- PIR motion sensor

Each sensor measures a different type of physical condition.

## 3. Output Devices

Output devices allow the IoT system to perform an action.

Examples include:

- LED
- Buzzer
- OLED display
- Relay
- Motor
- Water pump

For example, a soil moisture sensor can detect dry soil, and the microcontroller can turn on a water pump automatically.

## 4. Basic Electronic Components

You may also need some basic components such as:

- Breadboard
- Jumper wires
- Resistors
- USB cable
- External power supply
- LEDs
- Push buttons

These components are useful for building and testing circuits.

## 5. Computer or Laptop

You need a computer or laptop to:

- Write Arduino code
- Upload programs to the microcontroller
- Install libraries
- View sensor readings
- Debug errors

## 6. Arduino IDE

We will mainly use **Arduino IDE** to program the ESP32 and NodeMCU.

Arduino IDE allows you to:

- Write code
- Compile the program
- Upload code to the board
- Use the Serial Monitor
- Install additional libraries

## 7. USB Cable

A USB cable is required to connect the microcontroller to your computer.

The cable is used for:

- Uploading code
- Providing power
- Serial communication

Make sure the USB cable supports **data transfer**, because some USB cables are designed only for charging.

## 8. Wi-Fi Connection

Most IoT projects require an internet connection.

ESP32 and NodeMCU can connect to a Wi-Fi network and communicate with IoT platforms.

For testing, you can use:

- Home Wi-Fi
- Campus Wi-Fi
- Mobile hotspot

## 9. IoT Platform

An IoT platform allows you to monitor data and control devices through the internet.

Some platforms that may be used in this IoT Lab include:

- Arduino IoT Cloud
- Blynk
- ThingSpeak

For example, temperature data from an ESP32 can be displayed on an online dashboard.
