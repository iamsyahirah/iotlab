This IoT Lab is organised to help you learn IoT step by step.

## Recommended Learning Order

1. Understand the basic concept of IoT.
2. Prepare the required hardware and software.
3. Learn how to use ESP32 or NodeMCU.
4. Connect sensors and output devices.
5. Connect the board to Wi-Fi.
6. Build a complete IoT project.

## Each Tutorial Includes

Most tutorials will include:

- Components required
- Circuit connection
- Pin configuration
- Arduino code
- Code explanation
- Expected output
- Troubleshooting tips

## How to Follow the Tutorial

### 1. Prepare the Components

Make sure you have all the required components before starting.

### 2. Build the Circuit

Follow the circuit diagram and check the pin connections carefully.

### 3. Upload the Code

Open Arduino IDE, copy the example code, select the correct board and port, then upload the program.

### 4. Check the Output

Use the Serial Monitor, OLED display, or IoT dashboard to check the result.

### 5. Troubleshoot

If the project does not work:

- Check the wiring
- Check the selected board
- Check the COM port
- Check the installed libraries
- Check the pin numbers
- Read the error message carefully

## Learn by Experimenting

Try changing small parts of the program such as the sensor threshold, delay time, or output behaviour.

This will help you understand how the IoT system works instead of only copying the code.
